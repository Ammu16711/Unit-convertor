# Unit Converter with Navigation

## Project Description
The Unit Converter is a Flutter application that converts values between different units. It provides separate options for Length, Weight, and Temperature conversion. Users can select units, enter a value, and view the converted result.

## Features
- Convert Length (Meter, Kilometer, Centimeter, Mile).
- Convert Weight (Kilogram, Gram, Pound).
- Convert Temperature (Celsius, Fahrenheit).
- Easy-to-use interface.
- Navigation between screens.
- Dropdown menus to select units.
- Displays converted results.

## Technologies Used
- Flutter
- Dart
- DartPad

## How to Run
1. Open https://dartpad.dev/.
2. Select Flutter.
3. Copy the project code.
4. Paste it into the editor.
5. Click Run to execute the application.
